## Installation

The program is the single file `RanchRngTool.py`. It needs:

- **Python 3.8 or later**
- **Tkinter with Tk 8.6 or later**, Python's standard GUI library

To check that Tkinter works, run `py -m tkinter` on Windows or `python3 -m tkinter` on macOS and Linux. A small window showing the Tk version should open.

### Windows

1. Install Python from [python.org](https://www.python.org/downloads/windows/).
   - Tkinter is included: keep the **tcl/tk and IDLE** option selected (it is by default).
2. Start the program in one of these ways:
   - double-click `RanchRngTool.py`
   - in a terminal opened in its folder, run `py RanchRngTool.py`

To start it without the console window, use `pyw RanchRngTool.py`, or rename the file to `RanchRngTool.pyw` and double-click it.

### macOS

Install a Python that includes Tk 8.6 in one of these ways:

- **[python.org](https://www.python.org/downloads/macos/) installer** (recommended): Tkinter is included.
- **Homebrew**: `brew install python python-tk`.

Then run `python3 RanchRngTool.py` in the Terminal.

Do not use the `python3` of Apple's Command Line Tools (`/usr/bin/python3`). It comes with the old Tk 8.5, which cannot load the program's images.

### Linux

Install Python and Tkinter with your distribution's package manager:

| Distribution | Command |
|---|---|
| Debian, Ubuntu, Linux Mint | `sudo apt install python3 python3-tk` |
| Fedora | `sudo dnf install python3 python3-tkinter` |
| Arch Linux, Manjaro | `sudo pacman -S python tk` |
| openSUSE | `sudo zypper install python3 python3-tk` |

Then start the program in one of these ways:

- run `python3 RanchRngTool.py`
- make the file executable once with `chmod +x RanchRngTool.py`, then start it with `./RanchRngTool.py`

## How the RNG works

### When the PID and the IVs are decided

- Mew and Phione are generated by the Wii when Hayley offers the trade, after you deposit a Leafeon and an Egg from the DS.
- **IVs**:
  - they come from three consecutive calls of the game's random number generator `rand()`, whose state follows this LCG algorithm at every call: `next_current_seed = current_seed × 0x41C64E6D + 0x3039`
  - the state just before those three calls is the **IVs seed**: it alone decides the six IVs
- **PID**:
  - it comes from the console's timer instead, so it cannot be predicted
  - the PID generation follows this ARNG algorithm: `PID = OSGetTick() × 0x6C078965 + 0x01`
  - if that PID would be shiny, the same formula is applied to it again, so Mew and Phione are never shiny

### Advances and seeds

- The game calls `rand()` mainly for the following reasons:
  - moving Pokémon and Miis on the ranch (various)
  - camera movements (+3 each time)
  - Pokédex descriptions appearing during the trade (+1 each time)
  - dice rolls (+3 if 2, 3, 4 / +5 if 1, 5, 6)
- At boot the game seeds `rand()` from the console's clock:
  - on a Wii the boot seed is in practice random, so you find your current seed from what the game shows: camera movements, Pokédex descriptions, dice rolls
  - on Dolphin emulator the boot seed is `Origin Seed + 0x39EF8B0 × seconds since 01/01/2000 00:00:00`, so a boot date gives a known seed

## Gecko code for PAL, USA and JPN

In the PAL (English, French, Italian and Spanish), USA and JPN versions the RNG advances during the
trade exactly as in the German version, with or without the code: at every **Yes → No → No** loop
the game draws Leafeon's Pokédex description with one `rand()` call, choosing between the Diamond
and the Pearl one. In these versions, though, the two descriptions have the same text, so you
cannot tell which one was drawn.

The [Gecko code](https://github.com/Real96/RanchRNGTool/blob/main/pokedex_color_cheat.txt) makes
the choice visible. Leafeon's name in the trade profile turns:

- **light blue** when the game drew the Diamond description
- **pink** when it drew the Pearl one

The code does not change the RNG in any way: it only changes the colour of the name.

To use it:

1. Enable the code for your version **before starting the game**. The file has one code each for
   PAL (every language), USA and JPN; each one does nothing on a different version.
   - On Dolphin: tick **Enable Cheats** in **Config → General**. Then right-click the game, open
     **Properties → Gecko Codes**, add the code and tick it.
   - On a Wii: use a loader that supports Gecko codes.
2. In `Seed from Dex`, choose **GER**: it reads the same kind of draw, between two descriptions.
3. Enter **Diamond** when the name is light blue and **Pearl** when it is pink.

## Trade Offset

When Phione and Mew are both offered after the same deposit, Hayley offers Phione first. Mew is
generated a number of `rand()` calls after the A press that **accepts** or **refuses** Phione's
trade:

| Version | Accepted | Refused |
|---|---|---|
| **GER** | 62 | 23 |
| **JPN Pt** | 6 × N + 44 | 6 × N + 16 |

- **GER**: measured on the PAL version, with only one favourite Pokémon shown on the ranch. The
  PAL, USA and JPN versions run the same code, so use **GER** for them too.
- **JPN Pt**: after the offer *Platinum Taiouban* shuffles the Pokémon on the ranch and places each
  of them again, about 6 calls per Pokémon. N is the number of Pokémon on the ranch.

The **Trade Offset** option, in the Generator and in Seed to RTC, takes this into account:

1. tick the box and choose **Accepted** or **Refused**
2. choose the version, **JPN Pt** or **GER**
3. with JPN Pt, enter N in **Ranch Pokémon**

Then:

- **Generator**: each row shows the IVs generated that many calls later. Current Seed and Advances
  stay those of the A press.
- **Seed to RTC**: Target Seed stays the IVs seed, for example from the Searcher. Advances leads to
  the A press, that many calls before the target.

Untick the option to work with IVs seeds directly.

## IVs filters: shortcuts, copy and paste

- **right-click** anywhere in the box (on macOS also Control+click) to open this menu:

|---|---|

## Club Look-See ranches

The owners of these ranches are the members of the *Club Look-See*. Some of their ranches have many
Pokémon and make the RNG advance quickly: Taruo's ranch in *Platinum Taiouban* (130 Bidoof and
Bibarel) makes about 320–370 advances per second.

- A member can visit you when you start the game. They say their member number and invite you to
  their ranch: accept to go there. This is the only moment when you can enter it.
- *Platinum Taiouban* also lets you go back to the ranches you have already visited, from the
  bulletin board (*けいじばん* → *みてみて☆クラブ*).
- To leave an owner's ranch, point at the door at the top left of the screen and press **A**.
- The members come in the order of their member number. Taruo (Bobbie in English) is No. 1, so he
  is the first to come.
- Each member comes once per round, even if you refuse the invitation. After the last one
  (No. 37, No. 40 in *Platinum Taiouban*), they come in random order.
- The first member comes at the first start after a ranch expansion is completed, if no other
  expansion is in progress. Then a new member can come every 5 days (4 in *Platinum Taiouban*).

The full list of the owners and of the Pokémon on their ranches, for every version, is in
[Club Look-See.md](https://github.com/Real96/RanchRNGTool/blob/main/Club%20Look-See.md).

### Cycling the members

If Taruo has already come, you can bring the next members until one with a good ranch comes. In
*Platinum Taiouban* you can also go back to any ranch you have already visited.

1. Set the console's clock at least 5 days (4 in *Platinum Taiouban*) after the last member's
   visit. On Dolphin, set the custom RTC.
2. Start the game: no member comes yet, but the game schedules the next visit and saves. Wait until
   you are on your ranch, then quit.
3. Start the game again (the same date is fine): the member comes and says their number. Accept the
   invitation if it is a ranch you want, otherwise refuse it.
4. Repeat from step 1.

Never set the clock back.

When all the members have come, each visit is a random member. In the versions without the
bulletin board, if the member is not one you want, press **HOME** and choose **Reset** while they
are still talking. The game saves the visit only after the conversation, so at the next start
another member is drawn. On Dolphin, change the custom RTC by a few seconds before you start
again, or the same member comes back.

Each member costs two starts, so choose ranches that are both large and near in the arrival order:
about 100–300 Pokémon, and a member number below 15. These are the ones that fit.

## Example: Mew with the IVs you want

This walk-through follows the Japanese guide (see [Credits](#credits)) on a real console with
*Platinum Taiouban*, adapted to this tool. With the PAL version in German it works the same, with
the GER descriptions and the GER `Trade Offset`; the PAL, USA and JPN versions also need the
[Gecko code](#gecko-code-for-pal-usa-and-jpn). Phione's trade is refused and Mew is received (you
can also accept it: see the note after the steps).

**Before you start**

- In your DS game (Diamond, Pearl or Platinum) you need a Leafeon and an Egg in the boxes.
- On the ranch, Hayley must be asking for both: her wanted list shows the Leafeon (for Phione) and
  the Egg (for Mew).
- Take all your own Pokémon back from the ranch, so that only Hayley's remain, and count them in
  the *Deposit Details* (<img height="30" alt="image" src="https://github.com/user-attachments/assets/32cab28e-146c-4bf5-ba86-8ea64648a498" />):
  with *Platinum Taiouban* this number goes in the `Ranch Pokémon` box.
- Register one of Hayley's Pokémon as favourite: point at it and press **A** on the circle above
  its head.
- Optional but very useful: an owner's ranch with many Pokémon, to advance the RNG quickly (see
  [Club Look-See ranches](#club-look-see-ranches)).

**Steps**

1. **Go to an owner's ranch.**
   - To advance quickly, you must already be in an owner's ranch when you find your seed. You can
     enter it only right after starting the game, when a Club Look-See member invites you (see
     [Club Look-See ranches](#club-look-see-ranches)).
   - In *Platinum Taiouban* you can also choose a ranch you have already visited from the bulletin
     board (*けいじばん* → *みてみて☆クラブ*).
   - Without an owner's ranch you can only advance on your own ranch, which is much slower.
2. **Find your seed.**
   - In the owner's ranch, enter 13–15 camera movements in **Seed from Camera** with
     **Bruteforce** on.
   - Check the result against **Next Cameras**.
3. **Choose a target.**
   - Right-click the result and choose **Set as Initial Seed in Generator**.
   - In the Generator, set the IVs you want and `Trade Offset` **Refused**, with **JPN Pt** and the
     number of Pokémon in **Ranch Pokémon** (**GER** for all the other versions).
   - Choose a Max Advances you can reach.
   - If nothing good comes up, restart the game for a new seed. Without the bulletin board of
     *Platinum Taiouban* this also loses the owner's ranch (see
     [Cycling the members](#cycling-the-members)), so you may prefer a larger Max Advances.
4. **Advance.**
   - Stay in the owner's ranch: Taruo's ranch in *Platinum Taiouban* advances the RNG by about
     320–370 per second.
   - Stop a few minutes before the target and leave the owner's ranch: point at the door at the
     top left of the screen and press **A**. Then find your seed again on your ranch with
     **Seed from Camera**: Bruteforce off, the seed of step 2 as Initial Seed, and a Max Advances
     above the advances made; 7–9 movements should be enough.
   - Set the new seed as Initial Seed in Generator and generate again: the target's Advances is
     what remains.
5. **Deposit.**
   - Connecting with the DS and depositing also take advances, about 1,800, so connect early
     enough.
   - Show only the favourite Pokémon on the ranch: the connection takes fewer advances.
   - The RNG stops on the green warning screen just before the connection: get the DS ready there.
   - Deposit only the Leafeon and the Egg, choose Goodbye, save and disconnect.
6. **Find your position.**
   - Hayley offers Phione for your Leafeon.
   - Loop **Yes → No → No** and enter each description in **Seed from Dex**, with the seed of
     step 4 as Initial Seed, until one result is left. 15 descriptions should be enough.
7. **Step to the target.**
   - Set that result as Initial Seed in Generator, and generate with your IVs and the `Trade Offset`
     settings of step 3.
   - The Advances of your target row is the number of descriptions still to see: keep looping and
     count them.
8. **Refuse Phione, receive Mew.**
   - After the last description, answer **No**, then **Yes** to *"Oh? You want to cancel
     trading?"*.
   - Hayley then offers Mew: go on and trade the Egg. The nature is random.

**Note**: To trade for Phione as well, accept its trade after the last description instead of
refusing it, and use `Trade Offset` **Accepted** in steps 3, 4 and 7.

## Limits

- Only the IVs can be manipulated: the nature and the PID come from the console's timer, which
  cannot be predicted.
- **Seed to RTC** works only on [Dolphin emulator](https://github.com/Real96/dolphin/releases).
- **Seed from Dex** works as it is only with *Platinum Taiouban* and with the German (PAL)
  version. The others need [Dolphin emulator](https://github.com/Real96/dolphin/releases) with the
  [Lua script](https://github.com/Real96/PokeLua/tree/main/Gen%204/Dolphin), or the
  [Gecko code](#gecko-code-for-pal-usa-and-jpn).
- **Seed from Dice** works only with *Platinum Taiouban*.
