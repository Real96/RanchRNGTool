# RanchRNGTool <img width="30" alt="Mew" src="https://github.com/user-attachments/assets/56565878-8215-4b9e-bd69-833044a78618" />

Useful tool for Mew RNG manipulation on My Pokémon Ranch.

It supports every WiiWare release:

- *My Pokémon Ranch* (GER)
- *Minna no Pokémon Bokujō: Platinum Taiouban* (JPN)
- *My Pokémon Ranch* (PAL/USA) (Emulator or Gecko code necessary)
- *Minna no Pokémon Bokujō* (JPN) (Emulator or Gecko code necessary)

## Installation

The program is the single file `RanchRngTool.py`. It needs:

- **Python 3.8 or later**
- **Tkinter with Tk 8.6 or later**, Python's standard GUI library.

To check that Tkinter works, run `py -m tkinter` on Windows or `python3 -m tkinter` on macOS and Linux. A small window showing the Tk version should open.

### Windows

1. Install Python from [python.org](https://www.python.org/downloads/windows/).
   - Tkinter is included: keep the **tcl/tk and IDLE** option selected (it is by default).
2. Start the program in one of these ways:
   - double-click `RanchRngTool.py`
   - in a terminal opened in its folder, run `py RanchRngTool.py`.

To start it without the console window, use `pyw RanchRngTool.py`, or rename the file to `RanchRngTool.pyw` and double-click it.

### macOS

Install a Python that includes Tk 8.6 in one of these ways:

- **[python.org](https://www.python.org/downloads/macos/) installer** (recommended): Tkinter is included.
- **Homebrew**: `brew install python python-tk`.

Then run `python3 RanchRngTool.py` in the Terminal.

Do not use the `python3` of Apple's Command Line Tools (`/usr/bin/python3`). It comes with the old Tk 8.5, which cannot load the program's images.

### Linux

Install Python and Tkinter with your distribution's package manager:

| Distribution | Command |
|---|---|
| Debian, Ubuntu, Linux Mint | `sudo apt install python3 python3-tk` |
| Fedora | `sudo dnf install python3 python3-tkinter` |
| Arch Linux, Manjaro | `sudo pacman -S python tk` |
| openSUSE | `sudo zypper install python3 python3-tk` |

Then start the program in one of these ways:

- run `python3 RanchRngTool.py`
- make the file executable once with `chmod +x RanchRngTool.py`, then start it with `./RanchRngTool.py`.

## How the RNG works

### When the PID and the IVs are decided

- Mew and Phione are generated by the Wii, when Hayley offers the trade after a deposit of Leafeon and an Egg, from the DS.
- **IVs**:
  - they come from three consecutive calls of the game's random number generator `rand()`, whose state follows this LCG algorithm at every call: `next_current_seed = current_seed × 0x41C64E6D + 0x3039`
- **PID**:
  - it comes from the console's timer instead, so it cannot be predicted
  - the PID generation follows this ARNG algorithm: `PID =  OSGetTick() × 0x6C078965 + 0x01`

### Advances and seeds

- The game calls `rand()` mainly for the following reasons:
  - moving Pokémon and Miis on the ranch (various)
  - Camera movements (+3 each time)
  - Pokédex descriptions appearing during the trade (+1 each time)
  - Dice rolls (+3 if 2, 3, 4 / +5 if 1, 5, 6)
- At boot the game seeds `rand()` from the console's clock:
  - on a Wii the boot seed is in practice random, so you find your current seed from what the game shows: camera movements, Pokédex descriptions, dice rolls
  - on Dolphin emulator the boot seed is `Origin Seed + 0x39EF8B0 × seconds since 01/01/2000 00:00:00`, so a boot date gives a known seed

Then search in one of two ways:

- **From an Initial Seed** (Bruteforce off):
  - the current seed is searched between Min Advances and Max Advances after the Initial Seed
  - use it when you know an earlier seed, for example from your previous search; 7–9 movements are usually enough
  - Max Advances must cover the advances made since that seed.
- **Bruteforce** (ticked):
  - every state of the RNG cycle is tried, so no seed is needed and the Settings fields are greyed out
  - it needs at least 13 movements other than Not Clear; 13–15 are usually enough.

Results:

| Column | Meaning |
|---|---|
| Current Seed | The `rand()` state right after the last movement you entered. |
| Advances | Advances from the Initial Seed to the Current Seed; empty after a bruteforce. |
| Next Cameras | The next 3 movements, to check the result. |

Tips:

- Keep pressing the Wii Remote's **2** button (<img height="30" alt="image" src="https://github.com/user-attachments/assets/f4d26b44-d223-4b46-a57d-6658a48094ee" />) while you watch, to hold the
  characters' attention. Otherwise extra advances happen and the search fails.
- Focus-lock any character: point at its body and press **A**. *Focus Lock* then appears at the bottom left. This also prevents extra advances.
- To rest your fingers, pause with the **HOME** button after each movement you enter: the RNG does not advance during the pause. Press 2 again as soon as you are back in the game.
- With several results, or to check one, keep watching and compare with **Next Cameras**.

### Seed from Dex

<div align="center"><img width="609" height="672" alt="image" src="https://github.com/user-attachments/assets/80afad75-8949-41f0-960b-33dc3439a5b4" /></div>
<br>&nbsp;


Finds your current seed from Leafeon's Pokédex descriptions during Phione's trade offer. Only two
versions show descriptions that can be told apart; choose yours with the radio buttons:

| Option | Version | The two descriptions |
|---|---|---|
| **JPN Pt** | *Platinum Taiouban* (JPN) | Diamond/Pearl (*しょくぶつ…*) and Platinum (*きほんてき…*) |
| **GER** | PAL, in German | Diamond (*…ein Pflanze…*) and Pearl (*…eine Pflanze…*) |

In the other versions Leafeon's descriptions all read the same.

To see the descriptions:

1. When Hayley offers Phione for your Leafeon, answer **Yes → No → No**, again and again:
   - **Yes** shows Leafeon with a description, drawn by exactly one `rand()` call
   - **No** refuses the trade
   - the second **No** answers *"Do you want to stop the trade?"*, so the offer comes back
2. Enter each description with its button, in order.
3. Search between Min Advances and Max Advances after the Initial Seed.

This tab has no bruteforce, because each description tells very little: start from a seed found
with `Seed from Camera` or `Seed from Dice`.

Results:

| Column | Meaning |
|---|---|
| Current Seed | The `rand()` state right after the last description you entered. |
| Advances | Advances from the Initial Seed to the Current Seed. |
| Next Descriptions | The next 5 descriptions: D/P or Pt with JPN Pt, D or P with GER. |

Each further Yes → No → No takes exactly one advance. This is how you step to the exact advance
you need.

### Seed from Dice

*JPN Platinum Taiouban only* (the tab says *JPN Pt only*). It finds your current seed from dice
rolls.

- The dice (*さいころ*) is one of the toys that come out of the toy box.
- In free mode, grab it with **A+B** and release it to roll it. Keep pressing **2** meanwhile, as
  with the cameras.
- Each roll takes 3 calls, or 5 when it shows a 1, 5 or 6.

Enter the faces with the die buttons, then search in one of two ways:

- from an Initial Seed
- with **Bruteforce**, which needs at least 13 rolls

Results: **Current Seed** (right after the last roll), **Advances** and **Next Rolls**, the next 5
faces.

### Entries list

The Camera, Dex and Dice tabs list your entries, numbered, in the **Entries** box:

- every button you press adds one entry;
- **Remove**, or Delete / Backspace in the list, removes the selected entries, or the last one if
  none is selected;
- **Clear** empties the list.

## Trade Offset

When Phione and Mew are both offered after the same deposit, Hayley offers Phione first. Mew is
generated a number of `rand()` calls after the A press that **accepts** or **refuses** Phione's
trade:

| Version | Accepted | Refused |
|---|---|---|
| **GER** | 62 | 23 |
| **JPN Pt** | 6 × N + 44 | 6 × N + 16 |

- **GER**: measured on the PAL version, with only one favourite Pokémon shown on the ranch.
- **JPN Pt**: after the offer *Platinum Taiouban* shuffles the Pokémon on the ranch and places each
  of them again, about 6 calls per Pokémon. N is the number of Pokémon on the ranch.

The **Trade Offset** option, in the Generator and in Seed to RTC, takes this into account:

1. tick the box and choose **Accepted** or **Refused**;
2. choose the version, **JPN Pt** or **GER**;
3. with JPN Pt, enter N in **Ranch Pokémon** (up to 1,500).

Then:

- **Generator**: each row shows the IVs generated that many calls later. Current Seed and Advances
  stay those of the A press.
- **Seed to RTC**: Target Seed stays the IVs seed, for example from the Searcher. Advances leads to
  the A press, that many calls before the target.

The option is on at start, with Accepted, JPN Pt and 40 in Ranch Pokémon. Untick it to work with
IVs seeds directly: the version and Ranch Pokémon are then greyed out. Ranch Pokémon is greyed out
with GER too, and a search with JPN Pt asks for it if it is empty.

## Moving seeds between tabs

Right-click a row of a results table:

| From | Menu entry | Effect |
|---|---|---|
| Searcher | **Set Seed as Target Seed** | Puts the seed in the Target Seed of Seed to RTC. |
| Seed to RTC | **Set as Initial Seed in Generator** | Puts the boot seed in the Initial Seed of the Generator. |
| Seed from Camera, Dex, Dice | **Set as Initial Seed in Generator** | Puts the current seed in the Initial Seed of the Generator. |

You stay in the same tab, and its status bar confirms where the seed went.

## IVs filters: shortcuts, copy and paste

In the **IVs** box of the Generator and of the Searcher:

- **click** a stat's name (HP, Atk, Def, SpAtk, SpDef, Spd): that stat accepts any value, 0–31;
- **Ctrl+click** (**⌘+click** on macOS) a stat's name: that stat must be 31;
- **right-click** anywhere in the box (on macOS also Control+click) to open this menu:

| Entry | Effect |
|---|---|
| **Copy IVs to clipboard** | Copies the filters as `0/0/0/0/0/0-31/31/31/31/31/31`: the six Min values, a dash, the six Max values, in the order PS/Atk/Def/SpAtk/SpDef/Spd. |
| **Paste IVs from clipboard** | Sets the filters from text in that format, for example copied from the other tab or sent by someone. Spaces are allowed. Other text shows *"The clipboard text did not match the expected format."* |
| **Clear IVs** | Min 0 and Max 31 for every stat. |
| **Set 6IVs** | Min and Max 31 for every stat. |

Copying and pasting between the Generator and the Searcher is the quickest way to use the same
filters in both.

## Results tables

- **Sort**: click a column title. The first click sorts ascending (▲), the next ones switch between
  ▲ and ▼.
- **Resize**: drag the line between two column titles.
- **Select** a rectangle of cells:
  - click a cell and drag;
  - or extend the selection with Shift+click or Shift+arrows;
  - **Ctrl+A** (⌘A) selects everything.
- **Copy**:
  - **Ctrl+C** (⌘C) copies the selected cells as tab-separated text, which pastes as cells into
    Excel, LibreOffice Calc or Google Sheets;
  - a **double-click** copies the value of one cell.
- **Move** the selection:
  - with the arrows, Page Up and Page Down;
  - Home and End go to the first and last column;
  - Ctrl+Home and Ctrl+End go to the first and last row.
- **Scroll** with the mouse wheel or the scroll bar.

Tables stay fast with millions of rows. The window can be resized from every side and maximized:
the boxes and the tables follow its size.

## Input fields

Fields correct themselves while you type or paste:

Press **Enter** in any field to start the search.

Right-click a field (on macOS also Control+click) for the usual editing menu:

- **Undo** and **Redo**, also with Ctrl+Z and Ctrl+Y (Ctrl+Shift+Z on Linux, ⌘Z and ⇧⌘Z on
  macOS); a run of typing is undone at once;
- **Cut**, **Copy** and **Delete**, when some text is selected;
- **Paste**, when the clipboard holds text: the field corrects it like typed text;
- **Select All**.

The IV boxes keep their own menu (see
[IVs filters](#iv-filters-shortcuts-copy-and-paste)).

## Example: Mew with the IVs you want

This walk-through follows the Japanese guide (see [Credits](#credits)) on a real console with
*Platinum Taiouban*, adapted to this tool. With the PAL version in German it works the same, with
the GER descriptions and the GER `Trade Offset`. Phione's trade is refused and Mew is received.

**Before you start**

- In your DS game (Diamond, Pearl or Platinum) you need a Leafeon and an Egg.
- On the ranch, Hayley must be asking for both: her wanted list shows the Leafeon (for Phione) and
  the Egg (for Mew).
- Take all your own Pokémon back from the ranch, so that only Hayley's remain, and count them in
  the breakdown (*うちわけ*): with *Platinum Taiouban* this number goes in **Ranch Pokémon**.
- Register one of Hayley's Pokémon as favourite: point at it and press **A** on the circle above
  its head.
- Optional but very useful: Taruo's ranch (*タルオの牧場*), whose 130 Bidoof and Bibarel advance the
  RNG quickly. It appears after the ranch is fully expanded and the game has been started a few
  times.

**Steps**

1. **Find your seed.**
   - Enter 13–15 camera movements in **Seed from Camera** with **Bruteforce** on.
   - Check the result against **Next Cameras**.
2. **Choose a target.**
   - Right-click the result and choose **Set as Initial Seed in Generator**.
   - In the Generator, set the IVs you want and `Trade Offset` **Refused**, with **JPN Pt** and the
     number of Pokémon in **Ranch Pokémon** (**GER** for the PAL version in German).
   - Choose a Max Advances you can reach: the guide searches up to about 4,000,000, a little over
     3 hours at Taruo's ranch.
   - If nothing good comes up, restart the game for a new seed.
3. **Advance.**
   - Taruo's ranch advances the RNG by about 320–370 per second.
   - Stop a few minutes before the target. Then find your seed again with **Seed from Camera**:
     Bruteforce off, the seed of step 1 as Initial Seed, and a Max Advances above the advances
     made; 7–9 movements are enough.
   - Set the new seed as Initial Seed in Generator and generate again: the target's Advances is
     what remains.
4. **Deposit.**
   - Connecting with the DS and depositing also take advances, about 1,800 in the guide, so
     connect early enough.
   - Show only the favourite Pokémon on the ranch: the connection takes fewer advances.
   - The RNG stops on the green warning screen just before the connection: get the DS ready there.
   - Deposit only the Leafeon and the Egg, choose Goodbye, save and disconnect.
5. **Find your position.**
   - Hayley offers Phione for your Leafeon.
   - Loop **Yes → No → No** and enter each description in **Seed from Dex**, with the seed of
     step 3 as Initial Seed, until one result is left. In the guide 15 descriptions were enough.
6. **Step to the target.**
   - Set that result as Initial Seed in Generator, and generate with your IVs and the `Trade Offset`
     settings of step 2.
   - The Advances of your target row is the number of descriptions still to see: keep looping and
     count them. A tally counter helps.
7. **Refuse Phione, receive Mew.**
   - After the last description, answer **No**, then **Yes** to *"Do you want to stop the
     trade?"*.
   - Hayley then offers Mew: go on and trade the Egg. The nature is random.

To trade for Phione as well, accept its trade after the last description instead of refusing it,
and use `Trade Offset` **Accepted** in steps 2, 3 and 6.

## Limits

- Only the IVs can be chosen: the nature and the PID come from the not predictable console's timer.
- **Seed to RTC** works only on Dolphin emulator.
- **Seed from Dex** works only with *Platinum Taiouban* and with the German (PAL) version. You need Dolphin emulator or Gecko code for all the others.
- **Seed from Dice** works only with *Platinum Taiouban*.
