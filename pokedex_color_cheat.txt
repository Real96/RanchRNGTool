Pokédex version colour cheat for the Seed from Dex method
=========================================================

In the trade profile the Pokémon's name turns light blue when the game drew the
Diamond Pokédex text and pink when it drew the Pearl one (white for an Egg).
Every Yes -> No -> No loop draws once: enter Diamond for blue and Pearl for pink
in the Seed from Dex tab with the GER version.

Each code installs itself only if the game is the build it was made for.
